Carbon Control v1.2.0 面向 ThinkPad X1 Carbon Gen 8 的 i5-10210U 与 i5-10310U 版本，提供原生 Windows 温度监控和风扇曲线编辑。

## 本版功能

- 每秒显示 CPU 温度、核心平均频率、整包功耗和使用率，以及 Intel 核显使用率、核显功耗。
- 显示风扇 RPM 与最近 60 秒温度趋势。
- 系统自动、安静、均衡、强冷、自定义曲线及手动 0–7 档策略。
- 拖动绘制 2–12 节点曲线，支持点击添加、右键删除、数值微调、撤销和重做。
- 三个可命名的曲线存档，支持保存、覆盖、载入和直接应用；旧配置中的自定义曲线自动迁移到第一个槽位。
- 监控总览、风扇页面和托盘菜单提供「全速 · 7 档」；再次点击返回原策略或原手动档位。
- 单例主程序、任务栏托盘、开机启动、Dark / Light 及跟随系统主题，滚动条和下拉菜单同步换色。
- 导出硬件检测报告，本地保存主题、曲线及使用习惯。

## 风扇通信改进

风扇模式和 RPM 每 5 秒合并读取，同档位每 15 秒保活，减少重复读写。修改档位或应用曲线时立即唤醒控制线程，下发后读回确认。补充 EC 兼容读取、有限重试与退避；连续读取失败会恢复系统自动。

## 下载与启动

1. 下载并解压 `CarbonControl-v1.2.0-win-x64.zip`。
2. 从托盘退出旧版，打开解压目录中的 `CarbonControl.exe`。
3. 首次使用进入「设置 → 配置硬件组件」，安装官方 LibreHardwareMonitor 与 PawnIO 组件，再切换到「管理员模式」。硬件组件在首次配置时联网下载。
4. 在「风扇策略」绘制曲线，点击「保存并应用」；也可将曲线存入命名槽位。

系统要求：Windows 10 / 11 x64，.NET Framework 4.8。风扇接口适配 Lenovo 机型代码 20U9 / 20UA，CPU 为 i5-10210U 或 i5-10310U。

下载附件包括 Windows 便携程序 ZIP 与 `SHA256SUMS.txt` 校验文件。程序 ZIP 包含主程序和组件配置入口，首次硬件配置需要联网安装官方组件。
