新增电池、SSD 监控，以及与风扇曲线联动的低温办公／性能模式。

## 电池

- 独立电池页面：电量、满充容量与设计容量、健康度、循环次数、电压和预计续航。
- 显示充电或耗电功率，以及最近 60 秒趋势；功率表示电池端净充放电。
- 电池容量使用 Wh 显示，循环次数由 Windows 电池报告补充。

## SSD

- 显示各存储设备的温度、寿命剩余估计、空间使用率和累计读写。
- 电池每 2 秒、存储每 10 秒更新；设备采样与 CPU 采样分开。
- 不支持的字段显示「—」，寿命估计与剩余空间分开呈现。

## 性能与散热

- 监控总览新增「系统」「低温办公」「均衡」「性能」按钮。
- 低温办公关闭睿频并搭配均衡风扇曲线；均衡允许睿频；性能请求积极睿频并搭配强冷曲线。
- 使用独立 Windows 电源方案，设置会读回验证。切回系统或正常退出时恢复原方案。
- 风扇连接正常后应用联动曲线，之后仍可手动调整风扇。
- 包含上次异常退出的电源方案恢复。
- 在 Windows 中手动切换其他电源方案后，应用会同步显示系统模式，保留当前风扇选择。

## 验证

- 672 项逻辑断言通过，包含字段映射、电源方案切换、恢复和外部方案切换。
- 电池、SSD 页面及风扇联动交互检查通过，检查了深浅色和最小窗口布局。

## 更新

退出旧版托盘程序，解压 `CarbonControl-v1.4.0-win-x64.zip` 后打开 `CarbonControl.exe`。已有用户设置和曲线存档继续使用，硬件组件可从旧版复制整个 `hardware` 目录，或通过设置重新配置。
