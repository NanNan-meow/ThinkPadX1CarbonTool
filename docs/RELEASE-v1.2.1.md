修复首次安装硬件组件后，组件文件已存在却仍提示找不到 `LibreHardwareMonitorLib.dll` 的问题。

## 修复

- 统一使用应用目录下的 `hardware` 路径，加载前先检查组件文件，避免安装前的失败加载被 .NET 缓存。
- 配置组件后，在独立进程中检查监控库、依赖和风扇模块能否加载；成功后自动重启应用，重新读取组件及绑定配置。
- 「重新连接」完整重启并重新加载组件，不再直接显示未经验证的「已重新连接硬件」。
- 自动重启后返回设置页，保留已有主题、曲线和存档。

## 更新

1. 在托盘中退出旧版本。
2. 解压 `CarbonControl-v1.2.1-win-x64.zip` 并打开 `CarbonControl.exe`。
3. 可将原安装目录中的整个 `hardware` 文件夹复制到新版目录中；也可在设置中点击「配置硬件组件」。

已有用户设置保存在 `%LOCALAPPDATA%\CarbonControl`，会继续使用。

## 验证

新增程序集加载回归测试，覆盖安装前缺文件、安装后加载、含中文及空格的路径，以及 .NET 失败缓存的复现和清除。组件检查只加载程序集，不控制风扇。
