新增可配置的启动风扇策略：打开应用并确认温度与风扇连接正常后，自动启用预设或保存的曲线。

## 启动策略

- 在「设置 → 启动与托盘 → 启动风扇策略」选择系统自动、安静、均衡、强冷、自定义曲线或三个命名存档。
- 默认使用均衡策略；选择系统自动可继续由固件调节。
- 等待新鲜温度读数和风扇连接确认后再应用，每次启动只执行一次。
- 手动切换风扇模式后，启动策略不会再次覆盖当前选择。
- 修改启动设置会保存到本地，在下次启动时生效；空存档不可选择。

## 发布维护

新版 Release 的程序包与 SHA-256 校验文件下载验证成功后，自动删除较早的正式 Release，下载页面保留最新版本。

保留 v1.2.1 的组件加载修复：安装组件后校验并自动重启，重新加载 DLL 和绑定配置。

## 使用

退出旧版托盘程序，解压 `CarbonControl-v1.3.0-win-x64.zip` 并打开 `CarbonControl.exe`。已有设置和曲线存档会继续使用。首次硬件配置仍通过「设置 → 配置硬件组件」完成。
